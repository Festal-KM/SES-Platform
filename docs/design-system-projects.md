# SES Hub Design System — 案件管理タブ 仕様 v1.0

前提: `DESIGN_SYSTEM.md`（共通）と `DESIGN_SYSTEM_人材管理.md`（Table / Form / Step / Badge 対応表）を継承。シェル寸法は変更しない。

## 0. 画面一覧
| ID | 画面 | Main | Right |
|---|---|---|---|

## 2. 再利用ルール（案件管理）
1. 登録系画面は「Main = 入力、Right = AI 生成結果 + プレビュー + 送信」の 2 カラムを守る。送信ボタンは Right 最下部に置き、Main 内には置かない。
2. AI 機能の表示は 3 点に統一: 「AI」タグ 20h / Primary ボタンに wand アイコン / 結果 Badge（解析完了 ok, 解析中 info, 失敗 high）。
3. 公開プレビュー Card は人材・案件とも同じ構造（タイトル / Badge / KV 30h / リンク）。
4. 必須マークは `*` `--danger`、ラベル直後 gap 4。任意項目にマークは付けない。
5. placeholder は「例）…」で始める。値が入ったら `--text-1` に切替。
6. 一覧画面は人材一覧と同じ構造（Tabs 40 → Filter → 件数行 → Table 45h 行 → Right Detail Panel）。行クリックで右パネルを更新し、画面遷移しない。
7. 参考画像の Header 内タブ・Sidebar フッターユーザー・チャット未読バッジは基準シェルに合わせて採用しない（未読は Header 通知ドットに集約）。
