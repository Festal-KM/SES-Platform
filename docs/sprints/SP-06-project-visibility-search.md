## 1. 目的

案件の登録・**公開範囲（越境経路 1）**・案件検索・エンジニアの複合検索を通す。本スプリントの中核は 2 つある。

1. 🔴 **商流情報（エンド企業名・内部単価）を、公開範囲に含まれる相手の画面・エクスポート・通知のいずれにも出さない**（`F-013 AC-2` / `F-014 AC-3`）。**取得後に隠すのではなく、取得時の射影で分ける。**
2. 🔴 **Phase 1 の検索の並び順が決定的であること**（`F-009 AC-1` / `AC-2`）。**スコア・順位・重みに相当する表示項目を Phase 1 に置かない**（スコアは Phase 2 の `F-029`）。

> ⚠️ **`F-014 AC-3`（ゲート FAIL なら公開しない）の検証は SP-07（T-07-09）で行う。** 本スプリントでは公開範囲 API がゲートを呼ぶ**接続点**まで実装し、ゲート本体は SP-07 で入る。**この依存を放置しない** — SP-07 の完了判定に `F-014 AC-3` を含める。
