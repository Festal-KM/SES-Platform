## 5. テスト計画（方針）

- **ユニット**: スコア関数の決定性（同一入力 100 回で同一出力）。足切り・6 因子の境界値。重みを変えたときの順位変化。`domain-purity.test.ts` の維持。
- **結合**: `MatchCandidate` の生成と `rationale` の付与。根拠文の 1 リクエスト集約。
- **E2E**: 🔴 **匿名候補が自社エンジニアと同じ基準でスコアリングされ、匿名のままスコア順に並ぶ**（`CLAUDE.md` §5 の成功条件）。根拠文に 5 項目を超える情報が現れない。
- **外部 API のモック**: 🔴 **`MockAnthropicClient` を E2E と結合で同一実装として使う**（`docs/05` §17.5）。根拠文の固定応答 + スキーマ違反・タイムアウトの再現。
