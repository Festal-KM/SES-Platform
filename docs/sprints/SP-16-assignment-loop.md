## 1. 目的

🔴 **`CLAUDE.md` §1.3 が「このプロダクトの中核」と定める ⑥ → ① の還流**を成立させる。**この還流を切ると、本プロダクトは単なる案件管理 Excel の置き換えになる。** スコープ調整で最後まで守る（`docs/01` 章 4.3 の中核 1）。

あわせて **越境経路 5 の稼働参照（`F-065`）**、**保持期間削除（`F-046`）**、**代理閲覧（`F-060`）とお知らせ・機能フラグ（`F-061`）** を入れる。

🔴 **`CLAUDE.md` §5 Phase 2 の成功条件 1 つ目**「満了 60 日前に `ExtensionReview` が自動起票され担当者に通知される」を本スプリントで満たす。

`F-042`（稼働）/ `F-043`（満了アラート）/ `F-044`（延長論点 `renewal-advisor`）/ `F-045`（還流）/ `F-046`（保持期間削除）/ `F-065`（経路 5 の稼働参照）/ `F-060`（代理閲覧）/ `F-061`（お知らせ・機能フラグ）

## 5. テスト計画（方針）

- **ユニット**: 満了日の判定（`now` を引数で渡す）。還流の条件。保持期間の算出。
- **結合**: 🔴 **`assignment.expiry-scan` の「期限を過ぎ、かつ未処理」**（ジョブを 1 日止めても翌日に取り返す）。`retention.delete` の順序（S3 失敗で DB に進まない）。代理閲覧の read-only ロール接続。
- **E2E**:
  - 🔴 **#11 満了 60 日前の起票**（ジョブを 1 日止めても取りこぼさない）— `CLAUDE.md` §5 Phase 2 の成功条件 1。
  - 🔴 **#12 終了確定 → エンジニアが「待機予定」・案件が「後任募集」として候補母集団に現れる**（`F-045 AC-1` / `AC-2`）。
  - 🔴 **#14 代理閲覧中に主平面の実行系 API を直叩きして拒否される**（UI で隠すだけでないことの証明）。
  - 🔴 **#21 経路 5**（Phase 2 は稼働分）— 2 パートナーが同一案件に稼働を持つ状態で、A 社の `S-044` / `#80` に B 社の行・件数・合計・「他 N 件」が 0 件、応答 JSON に販売単価・エンド企業名・粗利・`ExtensionReview` の列が 0 個、`POST` / `PATCH` / `DELETE` を直叩きして 403、閲覧が `AuditLog` に残る、**ホストのプレビューが A 社の応答と一致する**。
  - #19 の Phase 2 分（AI 全停止でも `F-043` の起票が成立する）。
- **外部 API のモック**: 通知メールは宛先分類（SP-04 の単一経路）。`renewal-advisor` は `MockAnthropicClient`。
