## 1. 目的

契約（NDA / 基本契約 / 個別契約）の状態機械・テンプレート差し込み・**契約書の品質ゲート**（[Issue #15](https://github.com/Festal-KM/SES-Platform/issues/15) で 2026-09-01 に追加）・**冪等な送付**を成立させる。

🔴 **電子署名を接続していないテナントでも ⑤ 契約が完了できること**（`via='EMAIL'` でのメール添付送付。`BR-70` / `F-049 AC-9`）を本スプリントで満たす。**電子署名の接続を、契約業務を完了できる条件にしない。**

## 4. テスト計画（方針）

- **ユニット**: `Contract` の状態遷移（許可 / 拒否の全網羅）。`mergeContract()` の決定性（同一入力で同一出力）。
- **結合**: CAS の競合（同時 2 リクエストで 1 回だけ `SENDING`）。`SendAttempt` の 2 本の `UNIQUE`。ゲート FAIL / 未実行 / ハッシュ不一致で `send.contract` が発火しない。
- **静的テスト**: `contract-resend-human-only.test.ts`（#16）/ `queue-attempts.test.ts`（`send.contract` の `attempts: 1`）。
- **E2E**:
  - 🔴 **#4 の契約書分** — `CONTRACT_DOCUMENT` のゲートが FAIL / 未実行 / ハッシュ不一致なら `send.contract` が発火しない。
  - 🔴 **#22 の前半** — **電子署名を接続せずに** 契約作成 → ゲート → `via='EMAIL'` で送付 → 締結を記録 → `Assignment` 生成 が完了する（`F-049 AC-9`）。
  - 🔴 **`CLAUDE.md` §5 Phase 3 の成功条件 1** — 契約書の送付が冪等（二重実行しても外部 API 呼び出しが 1 回）。
- **外部 API のモック**: メール送付は分類 3（相手方）であり**全非本番環境でモック**。**電子署名は SP-18**。

## 5. 完了判定（方針）

1. `F-047`（**`AC-6` の `SUSPENDED` / `CLOSING` 分を除く**）/ `F-048` の全 AC と、`F-020 AC-1` の契約書分が green。
   - 🔴 **`F-047 AC-6`（テナントが `SUSPENDED` / `CLOSING` の間は `DRAFT` → `SENDING` が拒否される）は本スプリントでは成立しない。** `requireExecutable` への `SUSPENDED` の追加は **SP-20 の `T-20-05`**（`F-004 AC-7` の完成）であり、そこでしか green にならない。🔴 **`T-20-05` には既に逆参照が書かれている**（「SP-17 の完了判定が本タスクへ送っている分である」。SP-20 §4 の T-20-05 行）。**Phase 3 の再計画で SP-20 を分割・改稿する場合も、この逆参照を維持すること** — SP-03 → `T-20-05`、SP-06 → `T-12-02`、SP-11 → `T-17-08` / `T-19-08` と**同じ書きぶりで揃えてある**。
   - **到達不能な条件を完了判定に書かない**（`MODE: REVIEW` は 1 件でも NG なら `PHASE_INCOMPLETE` とするため、書くとこのスプリントが永久に閉じない）。
2. 🔴 **契約書の送付が冪等であること（二重実行しても外部 API 呼び出しが 1 回）をテストで証明できる**（`CLAUDE.md` §5 Phase 3 の成功条件 1）。
3. 🔴 **契約書が品質ゲートを経ずに `SENDING` へ進めない。** FAIL の解消手段は元データの修正と再実行のみ。**発注書はゲート対象でない。**
4. 🔴 **`SENDING` は片道で自動リトライが存在せず、再送は `SEND_FAILED → DRAFT` を経た人間の明示操作のみ**（呼び出し元が 1 ファイルに限られることを静的テストが固定）。
5. 🔴 **`SEND_FAILED` / `WITHDRAWN` / `EXPIRED` が別の表示・別の集計として扱われる。**
6. 🔴 **電子署名を接続していないテナントでも ⑤ 契約が完了できる。**
7. 🔴 **`EXECUTED` に到達した契約書の内容を書き換えられない**（訂正は新しい `Contract`）。
