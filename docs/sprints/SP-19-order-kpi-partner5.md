## 5. テスト計画（方針）

- **ユニット**: 転換率の算出（分母の除外が正しいこと。境界値）。
- **結合**: `F-050` の `CHECK` 制約。`F-051` の分母（`GATE_FAILED` / `SUBMIT_FAILED` / `DECLINED` / `EXPIRED` / `WITHDRAWN_BY_HOST` を混ぜたデータで分母が変わらない）。C9 の契約分。
- **静的テスト**: `counterparty-readonly.test.ts`（#17。`partner/**` が `GET` 以外を export しない / `extensionReview` の識別子が現れない）。
- **E2E**: 🔴 **#21 の Phase 3 分** — 2 パートナーが同一案件に契約を持つ状態で、A 社の `S-045` / `#81` / `#82` に B 社の行・件数・合計・「他 N 件」が 0 件、応答 JSON に販売単価・エンド企業名・粗利の列が 0 個、**ドラフト版の DL が 404**、`POST` / `PATCH` / `DELETE` を直叩きして 403、閲覧が `AuditLog` に残る、ホストのプレビューが A 社の応答と一致する。
- **外部 API のモック**: 本スプリントは外部送信を伴わない（DL は S3 の署名付き URL）。
