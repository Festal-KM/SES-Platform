## 4. 🔴 なぜ 5 段に分けるか（`Q-04-5` = 既定 ①）

**1 スプリントで全画面を一斉に置き換えると、回帰検出器（E2E 71 ケース / render 41 本 / 静的 57 本）が一度に全部赤くなり、どの変更が壊したか分からなくなる。** 段ごとに緑に戻せるようにする。

🔴 **これは「工程を刻む」話ではなく、検出器を生かしたまま進むための唯一の方法である。** 全画面を同時に触ると、①落ちた 30 本のうちどれが**挙動の回帰**でどれが**セレクタの巻き添え**かを人間が仕分けることになり ②仕分けの過程で「とりあえず期待値を直す」が起き ③その 1 件が `CLAUDE.md` §7 の「0 件」を破る回帰でも気づけない。**段に分ければ、各段の終わりに「全数緑」という状態が必ず在り、赤は必ずその段の差分に由来する。**
